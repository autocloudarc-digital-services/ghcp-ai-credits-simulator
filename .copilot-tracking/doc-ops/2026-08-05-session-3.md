## Requirements

Create two SVG diagrams, one for each implementation guide, using the supplied
GitHub Enterprise Cloud AI Credits budget and consumption flow as the quality,
format, and visual-pattern reference. Maintain only SVG assets, index them, and
integrate each indexed diagram with its corresponding guide.

## Discovered Issues

### Pattern Compliance

Seventeen visual and integration findings were identified. Both diagrams need
numbered, color-coded bands; explicit decisions and outcomes; accessible
metadata; responsive SVG output; concise labels; a semantic legend; and an
early linked embed in the corresponding guide. The design will use a stacked
landscape layout inspired by the supplied reference without copying its
artwork or unsupported provider claims.

### Accuracy Discrepancies

The supplied reference implies automatic pool creation, fixed routing,
universal precedence, and guaranteed stop behavior that this repository does
not establish. The internal diagram must distinguish provider evidence,
application estimates and heuristics, and manual customer action. The external
diagram must require customer validation of rates, scope, precedence, alerts,
and enforcement behavior. Unknown values must never be represented as zero.

### Missing Documentation

Eight diagram-coverage gaps were identified. The guides lack an intuitive map
connecting evidence, profiles, decisions, rollout, monitoring, and rollback.
The internal diagram needs the application workflow and read-only boundary.
The external diagram needs the provider-neutral governance lifecycle and four
separate control layers. Both need source files, rendered SVGs, accessible alt
text, and full-size links.

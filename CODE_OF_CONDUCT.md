## Our Commitment

This project adopts the standards of the
[Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).
We expect everyone participating in issues, discussions, pull requests, reviews,
and other project spaces to help maintain a welcoming, respectful, and inclusive
community.

Treat others with empathy, respect differing perspectives, and give constructive
feedback. Harassment, discrimination, personal attacks, disruptive behavior, and
disclosure of another person's private information without permission are not
acceptable. These expectations also apply when representing the project outside
its community spaces.

## Responsible Use of AI

Contributors remain responsible for everything they submit, including
AI-generated content. Review and revise generated contributions before sharing
them, and validate their accuracy, relevance, and suitability for the project.

## Reporting and Enforcement

This repository is maintained by autocloudarc-digital-services, not Microsoft.
Report conduct concerns privately to the project maintainer at
[autocloudarc@autocloudarc.dev](mailto:autocloudarc@autocloudarc.dev).
Do not post sensitive reports or personal information in public issues or pull
requests.

Maintainers will review reports, respect the privacy and security of reporters,
and take appropriate corrective action. Actions may include removing unsuitable
content, requesting changes in behavior, or restricting participation.

For questions about Microsoft's policy, see the
[Microsoft Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/).
Security vulnerabilities should instead follow the private reporting process in
our [Security Policy](SECURITY.md).

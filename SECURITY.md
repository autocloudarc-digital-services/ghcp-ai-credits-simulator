## Reporting a Vulnerability

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/autocloudarc-digital-services/ghcp-ai-credits-simulator/security/advisories/new).

Do not disclose a suspected vulnerability in a public issue, discussion, pull
request, or other public channel. Include the affected component, reproduction
steps, potential impact, and any suggested mitigation in your report. Remove
credentials, personal data, and other secrets from all supporting material.

Maintainers will acknowledge reports as soon as practical, assess their impact,
and provide status updates while remediation is in progress. Coordinated public
disclosure should occur only after a fix or mitigation is available.

## Supported Versions

Security fixes are applied to the latest revision of the default branch. Older
commits, forks, and modified deployments are not supported.

## Security Updates

Confirmed vulnerabilities and available remediations are documented through
GitHub Security Advisories. Upgrade to the latest revision and follow any
deployment-specific instructions in the advisory.
